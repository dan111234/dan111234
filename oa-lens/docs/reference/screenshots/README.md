# RevSeller 참고 스크린샷 목록

RevSeller가 설치된 Chrome에서 아래 화면을 찍어 이 폴더에 파일명 그대로 저장하세요. Windows는 `Win + Shift + S`로 영역 캡처를 할 수 있습니다.
개인 참고용입니다. 이 폴더는 `.gitignore`에 포함되어 저장소에 올라가지 않습니다.

상품은 **변형(사이즈·색상)이 있고, FBA 셀러가 여러 명이고, 판매 제한(Appr/Rstr)이 있는 상품** 하나를 골라 같은 상품으로 찍으면 비교하기 좋습니다.

| 파일명 | 화면 |
|---|---|
| `01-widget-default.png` | 상세페이지 메인 위젯, 처음 열렸을 때 상태 (접힌 섹션 그대로) |
| `02-widget-all-open.png` | 30/90/180, Targets, Offers, Notes, Graphs를 모두 펼친 상태 (길면 2~3장으로 나눠서) |
| `03-header-badges-hover.png` | 헤더의 Sell/Appr/Rstr, Haz 배지에 마우스를 올렸을 때 툴팁 |

| `06-order-totals-popup.png` | Buy Cost 옆 `#` 버튼 팝업 |
